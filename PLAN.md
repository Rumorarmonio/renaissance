# План реализации

## Проект

Адаптивная страница интернет-магазина Banki.shop по макету Figma.

## Цель

Создать работающее Vue 2.7-приложение на TypeScript с каталогом товаров, поиском, корзиной, модальным описанием товара и публикацией на GitHub Pages.

## Этапы

1. Инициализировать Vue 2.7-проект на TypeScript, настроить Webpack, SCSS-архитектуру и code-style tooling.
2. Подготовить данные и локальные ассеты товаров из Figma.
3. Реализовать базовую адаптивную вёрстку страницы и карточек.
4. Добавить поиск по названиям товаров.
5. Подключить Pinia 2 и реализовать корзину с сохранением в `localStorage`.
6. Реализовать состояния кнопки покупки с задержкой 2 секунды.
7. Реализовать модальное окно товара и слайдер на Swiper.
8. Настроить GitHub Actions для сборки и публикации на GitHub Pages.
9. Проверить адаптивность, современные браузеры и соответствие макету.
