# Рабочие заметки проекта

## Проект

Адаптивная страница интернет-магазина Banki.shop по макету из Figma.

## Цель

Сверстать страницу каталога и реализовать поиск, добавление товаров в корзину, сохранение состояния и просмотр подробной карточки товара.

## Текущее состояние

Репозиторий подготовлен документацией. Исходный PDF изучен, требования зафиксированы в `SPEC.md`. Базовый Vue-проект и зависимости установлены, функциональные модули ещё не реализованы.

## Ключевые решения

- Vue 2.7 и Options API.
- TypeScript и Webpack.
- Pinia 2.x для состояния корзины, `localStorage` для сохранения.
- Swiper для слайдера изображений.
- Node.js 16 для разработки и CI.
- Публикация через GitHub Actions на GitHub Pages.
- Товары и изображения переносятся из макета Figma.
- Swiper подключён через Vue 2-совместимые `swiper@5.4.5` и `vue-awesome-swiper@4.1.1`.
- GitHub Pages публикуется через `.github/workflows/deploy-pages.yml`; для project pages
  production-сборка получает `PUBLIC_PATH` с именем репозитория.

## Что уже сделано

- Создан и заполнен `SPEC.md`.
- Подготовлен базовый `.gitignore`.
- Созданы инструкции для агента, рабочие заметки и план реализации.
- Инициализирован Webpack-проект на Vue 2.7 и TypeScript.
- Подключены Pinia 2 и Swiper.
- Добавлены базовые команды запуска, проверки типов и production-сборки.
- Добавлен workflow GitHub Actions для сборки и публикации на GitHub Pages.
- Подключена базовая SCSS-архитектура в `src/styles/`: глобальный `main.scss` и Sass-only
  facade `_tools.scss` через `sass-loader` `additionalData`.
- Настроены ESLint, Prettier и Stylelint с профилем для Vue 2.7 + TypeScript + SCSS;
  добавлены совместимые с Node 16 зависимости и команды проверки.
- Удалены неиспользуемые интеграции Prettier с ESLint; согласованность `package.json` и
  `package-lock.json` проверена через `npm ci --dry-run`.

  обработки TypeScript в Vue 2 SFC добавлен `appendTsSuffixTo` в `ts-loader`.
